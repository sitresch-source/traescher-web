# traescher web

Website für ein Studio, das KMU- und Vereinswebseiten gestaltet.
Gebaut mit React + Vite, ganz in Schwarz/Weiß/Grau.

## Lokal starten

```bash
npm install
npm run dev
```

Dann im Browser die angezeigte Adresse öffnen (meist http://localhost:5173).

## Build für Produktion

```bash
npm run build
```

Erzeugt einen `dist/`-Ordner mit der fertigen, statischen Seite.

## Live schalten

Siehe Anleitung im Chat – kurz zusammengefasst: Code auf GitHub pushen,
dann das Repo bei vercel.com importieren. Vercel erkennt Vite automatisch
und deployed bei jedem Push neu.
